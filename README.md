**Diabetic Retinopathy Detection Using Deep Learning**

This project uses Deep Learning and Ensemble Learning techniques to detect and classify Diabetic Retinopathy from retinal fundus images into five stages: No DR, Mild, Moderate, Severe, and Proliferative DR.

The system uses three CNN architectures — InceptionResNetV2, ResNet50V2, and DenseNet121 — for feature learning and prediction. Their outputs are combined using a stacking ensemble approach with LightGBM and XGBoost to improve classification performance.

The project aims to assist in the early identification and severity assessment of Diabetic Retinopathy through automated retinal image analysis.

**Technologies Used:** Python, TensorFlow/Keras, CNN, LightGBM, XGBoost, Flask, and Google Colab.

**Dataset:** APTOS 2019 Blindness Detection.

**Note:** This project is intended for educational and research purposes and is not a substitute for professional medical diagnosis.
